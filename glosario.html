Glosario

Todos los términos de las clases, en un solo lugar. Cada uno linkea a dónde se explica en detalle.

1Modularización y React

Módulo Ver en la clase →

Un archivo de código con su propio espacio aislado, que decide explícitamente qué partes de sí mismo comparte con otros archivos.

Import Ver en la clase →

Traer a un archivo algo que otro módulo exportó, ya sea una librería instalada o un archivo propio.

Export (named export) Ver en la clase →

Decidir qué parte de un archivo va a estar disponible para quien lo importe. Un archivo puede tener varios named exports.

Export default Ver en la clase →

La forma de exportar "una cosa principal" por archivo. Al importarla no se usan llaves y se le puede poner cualquier nombre.

Componente Ver en la clase →

Una función de JavaScript que devuelve JSX (interfaz), en vez de un número o un string.

Composición Ver en la clase →

Combinar componentes entre sí, usando unos adentro de otros, como piezas de Lego.

Props Ver en la clase →

Los parámetros de la función-componente. Se pasan como atributos JSX y llegan agrupados en un objeto.

Destructuring Ver en la clase →

Forma corta de sacar valores de adentro de un objeto o un array, sin escribir objeto.propiedad cada vez.

children Ver en la clase →

Prop implícita que representa todo lo que se pone entre las etiquetas de apertura y cierre de un componente.

2Hooks y estados

Render Ver en la clase →

El momento en el que React ejecuta la función de un componente y calcula qué JSX tiene que mostrar en pantalla.

Estado Ver en la clase →

Un valor que React guarda asociado a un componente. Al actualizarlo con la herramienta correcta, dispara un nuevo render.

useState Ver en la clase →

Hook que declara una variable de estado. Devuelve un array de dos elementos: el valor actual, y una función para actualizarlo.

Renderizado condicional Ver en la clase →

Mostrar interfaz distinta según el estado, con operador ternario (? :), &&, o if / else.

Efecto secundario Ver en la clase →

Algo que un componente hace por fuera del render puro: pedir datos a un servidor, iniciar un timer, escuchar un evento.

useEffect Ver en la clase →

Hook para ejecutar efectos secundarios después de que el componente se dibuja en pantalla.

Array de dependencias Ver en la clase →

El segundo argumento de useEffect. Controla cuándo se vuelve a ejecutar el efecto.

Función de limpieza (cleanup) Ver en la clase →

Lo que un useEffect puede devolver, para desarmar algo (un timer, un listener) antes de correr de nuevo.

useRef Ver en la clase →

Hook para guardar un valor que persiste entre renders sin disparar un re-render, o para referenciar un elemento del DOM.

Prop drilling Ver en la clase →

Pasar una prop por varios componentes intermedios que no la usan, solo para que llegue a uno más profundo.

Context / Provider Ver en la clase →

Un valor disponible para toda una parte del árbol de componentes, sin pasarlo manualmente nivel por nivel.

useContext Ver en la clase →

Hook para leer el valor de un Context desde cualquier componente adentro de su Provider.

Hook propio (custom hook) Ver en la clase →

Una función que empieza con use y usa uno o más hooks de React por dentro, para reutilizar lógica con estado.
